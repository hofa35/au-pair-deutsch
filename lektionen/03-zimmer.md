## Wortschatz

|---|---|
| das Zimmer | the room |
| das Bett | the bed |
| der Schrank | the wardrobe |
| der Tisch | the table |
| der Stuhl | the chair |
| das Fenster | the window |
| die Lampe | the lamp |
| es gibt | there is, there are |
| hell | bright |
| gemütlich | cosy |

## Dialog

**Anna:** Mira, hier ist dein Zimmer.
**Mira:** Danke! Das Zimmer ist schön hell.
**Anna:** Es gibt ein Bett, einen Schrank und einen Tisch.
**Mira:** Gibt es auch eine Lampe?
**Anna:** Ja, hier ist die Lampe. Und das Fenster ist groß.
**Mira:** Das Zimmer ist sehr gemütlich. Hier fühle ich mich wohl.

## Grammatik Deutsch

Im Deutschen hat jedes Nomen einen Artikel: der, die oder das.

der Schrank · der Tisch · der Stuhl
die Lampe
das Zimmer · das Bett · das Fenster

Man kann den Artikel nicht raten. Lerne ihn immer zusammen mit dem Wort: nicht "Bett", sondern "das Bett".

Im Plural steht immer "die": die Zimmer, die Betten, die Lampen.

"Es gibt" sagt, was vorhanden ist. Es bleibt immer gleich, egal ob eines oder viele:

"Es gibt ein Bett." "Es gibt zwei Fenster."

Eine Sache fällt dabei auf: Bei Wörtern mit "der" wird aus "ein" ein "einen".

der Schrank → "Es gibt einen Schrank."
das Bett → "Es gibt ein Bett."
die Lampe → "Es gibt eine Lampe."

Lerne das vorerst einfach so mit. Warum das so ist, kommt in Lektion 6.

## Grammatik Englisch

In German every noun has an article: der, die or das. English only has "the", so this is new.

der Schrank · der Tisch · der Stuhl
die Lampe
das Zimmer · das Bett · das Fenster

You cannot guess which one a noun takes. Always learn the article together with the word: not "Bett" but "das Bett".

In the plural it is always "die": die Zimmer, die Betten, die Lampen.

"Es gibt" means "there is" or "there are". Unlike English, the form never changes:

"Es gibt ein Bett." (There is a bed.) "Es gibt zwei Fenster." (There are two windows.)

One thing to watch: after "es gibt", nouns with "der" change "ein" to "einen".

der Schrank → "Es gibt einen Schrank." (There is a wardrobe.)
das Bett → "Es gibt ein Bett." (There is a bed.)
die Lampe → "Es gibt eine Lampe." (There is a lamp.)

For now just learn these as fixed phrases. Lesson 6 explains the reason.

## Übung

Ergänze "der", "die" oder "das":

1. ___ Bett
2. ___ Schrank
3. ___ Lampe
4. ___ Fenster
5. ___ Stuhl

## Lösung

1. das Bett, 2. der Schrank, 3. die Lampe, 4. das Fenster, 5. der Stuhl

## Schreibübung

Beschreib dein eigenes Zimmer. Schreib fünf Sätze:

1. Fang an mit "Das ist mein Zimmer."
2. Drei Sätze mit "Es gibt ..."
3. Sag zum Schluss, wie dein Zimmer ist.

## Beispiellösung

Das ist mein Zimmer. Es gibt ein Bett und einen Tisch. Es gibt auch eine Lampe. Es gibt ein Fenster. Mein Zimmer ist klein, aber sehr gemütlich.

## Hörübung

Das ist mein Zimmer. Es ist klein, aber sehr gemütlich. Es gibt ein Bett, einen Schrank und einen Tisch. Das Fenster ist groß. Das Zimmer ist schön hell. Hier gibt es auch eine Lampe. Mein Zimmer ist hell und gemütlich. Hier fühle ich mich wohl.
